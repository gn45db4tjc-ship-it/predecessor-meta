# 2.21.3 — fresh-source recommendations

Daily collection now affects the role statistics that recommendations use. Previously, the presence of a retained Pred.gg cohort still gave its older rates priority over a new Statz download. Automatic meta presentation, hero/partner role performance and composition individual-performance comparisons now choose an eligible source for the whole bundle: a valid exact-patch Pred.gg collection when available, otherwise the available Statz dataset when compatible with the verified live patch family. Sources and rank cohorts are not pooled. Missing roles remain missing. Explicit source-table inspection still allows the saved observations to be read with their original dates.

Statz's 1.16 label is not re-labelled 1.16.4. Its exact match window and mode coverage remain unconfirmed and the interface says so. The statistics strip, hero/build/planning notices and composition mean identify the selected source. A changed patch family, missing fetch dates, retained/failed Statz collection or unverified live patch cannot activate it for automatic role recommendations. A valid partial exact-patch source can retain its successfully parsed role observations without inventing missing ones.

An authored tier's source comparison remains tied to the Pred.gg cohort it was reviewed against. Broader Statz rates cannot reactivate that judgment or imply a new editorial review. Retained Pred.gg counters no longer rank current draft suggestions. Live game prioritizes available same-role observations over retained Pred.gg rows, retains the selected row's sample, and never calls it a verified role-versus-role comparison when the source does not identify the opponent role. Other saved rows remain inspectable.

Verification: 21 focused JavaScript checks, 61 Python publication checks, and a real published-data evaluation across all six brackets. The latter checked every eligible hero/role statistic against its source and verified descending individual-performance ordering. Gold+ generated ten alternatives each for 2, 3 and 5 heroes while preserving Steel Jungle without inventing a role sample, and preserving unique roles. Source records were unchanged by those calculations. The source-only ZIP repeats the focused suites from a clean extraction. Browser and installation receipts are stored separately; prior full-suite/design evidence remains historical.

This builds on 2.21.2 and preserves its daily cloud schedule, Design Revision 2 themes/layout, builds, Live game, data/snapshots, settings and authored guidance. Pred.gg authorized access and a user choice about scheduling daily Codex strategic reviews remain outstanding. No Codex review automation is created by this release.
