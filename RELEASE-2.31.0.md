# 2.31.0 — visual redesign

The phone companion has a new midnight navy / ice blue dark theme and porcelain / cobalt light theme. Blue identifies navigation and actions. Observed statistics, calculated choices, reviewed advice and official descriptions retain separate category colors and explicit labels.

Meta uses larger portraits, stronger names and numbers, a clear build entry point, segmented role controls and labeled navigation icons. The narrow-phone header keeps the rank and refresh controls together. Hero pages have a distinct profile panel, clear section selection, separate pre-match loadout and purchase-order headings, and a numbered shopping list instead of a cramped item grid. Desktop shares the palette, typography and hierarchy.

Both themes retain source limitations, previous-dataset labels, samples and source dates. No statistics, engine rules, reviewed guidance, selected-build identity, fetch schedules or storage keys were changed. The 2.30.3 update flow remains available under More → Check app update and preserves picks, favorites and selected builds.

Validation is recorded in RELEASE-2.31.0-VERIFICATION.json. Final install, exact-head CI, deployment and live receipts are recorded separately in the release result. Physical phone, VoiceOver and other real assistive-technology acceptance are not claimed.

## Update and rollback

For the home-screen app, open More → Check app update → Update app. If still running a version earlier than 2.30.3, fully close it from the phone's app switcher and reopen while online. Do not delete the app or clear website data.

The Windows installation uses a verified source ZIP and hashed backup of replaced program files. Existing data, snapshots, settings and guidance are preserved. Quit the local app and run **Roll Back 2.31.0.bat** to restore the previous installed 2.30.2 interface. Public rollback is a revert of this release's merge on main through the existing verification and publication workflow.
