# 2.21.1 — independent source updates

14 September 2026. Built on the verified Design Revision 2 release. Its phone layouts, optional light theme, Builds and Live game pages remain.

## What changed

A failed Pred.gg collection previously caused the public publisher to discard successful Statz/Omeda downloads. A validated independent update now persists separately from the last complete success, survives relaunch, transfers through the existing data branch, and publishes with per-source dates and an explicit partial status.

Pred.gg records are retained only for the same bracket, identical verified patch version and unchanged official article fingerprint. Reapplying dated mechanics uses the existing official-field protections transactionally. A failed replay leaves fresh source data intact. No observation, sample count or original fetch time is rewritten. Retained evidence cannot silently reaffirm a reviewed tier or add current item-fit points. Composition averages are labelled calculated.

## Limits that remain

Pred.gg's public page returns a client-only shell to the actual Windows updater. Its anonymous statistics API query returned `Forbidden`; that query was not retried. Legitimate source access is needed to restore complete Pred.gg updates. Its retained samples still date from September 8. One historical official article failed during the Gold verification and remains a named source error.

An observation fetched today is not proof that the provider has ingested every match or exposes its full sampling window. Statz's 1.16 dataset label does not become an isolated 1.16.4 sample. Authored strategy retains its own review date. This release does not claim 100% current or complete statistical coverage.

The website remains free and readable while the PC is off. Available-source collection still uses the Windows updater; cloud statistical collection remains paused. No hosting subscription or API purchase was added.

## Repeating the shipped checks

Run `python -X utf8 -B -m unittest discover -s tests -p "test_static*.py"` and `node --test tests/independent_sources.test.cjs`. Node is for development checks only; the app still needs only Python's standard library. The older Design Revision 2 browser suites remain included as historical acceptance tooling, with their fixture requirements described in `RELEASE-VERIFICATION.md`.

## Installation and rollback

The installed app's settings, drafts, existing bundles and snapshots are preserved. New partial bundles use `last_available_<bracket>.json`; complete bundles keep their original files. The website publisher uses a separate `partial-bundles` directory. Rollback restores program files only; dated observations remain on disk. The installed `Roll Back 2.21.1.ps1` uses a hashed backup and does not delete data. Deployment and installation receipts are separate from this source report.
